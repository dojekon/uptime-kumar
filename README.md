# Uptime Kumar

Форк [Uptime Kuma](https://github.com/louislam/uptime-kuma) с расширенными возможностями управления инцидентами.

## Что добавлено

### Управление инцидентами

- **Создание инцидентов** вручную или автоматически при падении сервиса
- **Смена стадий**: зафиксировано → в работе → устранено
- **Хронология реагирования** (таймлайн) с отметками времени по каждой смене статуса
- **Post-mortem** — отчёт о причинах и решении, доступен для заполнения только после устранения инцидента
- Детали инцидента открываются в модальном окне с таймлайном, стадиями и post-mortem

### Публичная страница статуса (`/overview`)

- Карточки групп сервисов с гребёнкой доступности за 90 дней (60 временных отрезков)
- При клике на группу — модальное окно со списком сервисов и индивидуальными гребёнками
- Зелёный сегмент — сервис работал, красный — был недоступен, жёлтый — проверка, синий — обслуживание
- При наведении на сегмент — тултип с диапазоном дат
- При наведении на красный сегмент — дополнительно список связанных инцидентов (кликабельны)
- Клик по инциденту в тултипе — полное описание: контент, таймлайн реагирования, post-mortem
- Никаких ссылок в панель управления — чисто публичная страница

### Установка и запуск

```bash
git clone <url-репозитория>
cd uptime-kumar
npm install
npm run build
npm run start-server
```

Сервер запускается на `http://localhost:3001`.

### Основа

Uptime Kumar основан на Uptime Kuma и сохраняет все его возможности:

- Мониторинг HTTP(s) / TCP / Ping / DNS / Docker и др.
- Уведомления через Telegram, Discord, Slack, Email и 90+ сервисов
- Быстрый реактивный интерфейс
- 20-секундные интервалы проверки
- Мультиязычность
- 2FA
